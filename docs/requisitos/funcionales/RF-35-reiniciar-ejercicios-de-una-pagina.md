# RF-35 — Reiniciar ejercicios de una página

| Campo | Valor |
|---|---|
| **ID** | RF-35 |
| **Título** | Reiniciar ejercicios de una página |
| **Módulo** | M-8 Ejercicios |
| **Prioridad** | Baja |
| **Fase** | 4 |
| **Estado** | Pendiente |
| **Dependencias** | [RF-33](RF-33-escribir-respuestas-sobre-la-pagina.md) |
| **Reglas de negocio** | — |

## Descripción
El usuario puede borrar todas sus respuestas de una página para repetir el ejercicio.

## Justificación
Repetir ejercicios es parte del estudio antes de un examen.

## Criterios de aceptación
1. Tras confirmar, la página queda sin anotaciones del usuario y las de otros usuarios no se ven afectadas.
