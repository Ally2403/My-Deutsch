# RF-08 — Ver miembros del grupo

| Campo | Valor |
|---|---|
| **ID** | RF-08 |
| **Título** | Ver miembros del grupo |
| **Módulo** | M-2 Grupos |
| **Prioridad** | Media |
| **Fase** | 3 |
| **Estado** | Hecho |
| **Dependencias** | [RF-07](RF-07-unirse-a-un-grupo.md) |
| **Reglas de negocio** | RN-04 |

## Descripción
Cualquier miembro puede ver la lista de miembros (nombre, foto y rol).

## Justificación
Permite confirmar que todos los compañeros están dentro del grupo.

## Criterios de aceptación
1. La lista muestra nombre, foto y rol de cada miembro, y nunca datos de vocabulario o progreso (RN-04).
